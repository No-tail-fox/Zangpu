# Zangpu Python SDK

Python client for the signed Zangpu contract API. It supports caller-scoped model discovery, quota usage, JSON chat completions and SSE chat completions.

```powershell
python -m pip install .\sdk\python
```

See [`docs/api-sdk.md`](../../docs/api-sdk.md) for the Chinese integration guide, request-id retry rules and cURL examples.
